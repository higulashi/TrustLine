# 算法与创新边界

## 目标

灰度图提取的赛道中线可能受阴影、断线和误配影响。本项目研究如何把路径估计误差和观测范围用于前瞻距离与速度决策。

C99 核心使用固定大小数组。Python 负责图像渲染、车辆模型与评估，闭环运行直接调用 C 图像扫描和控制实现。

## 1. 从图像得到测量

输入为 188×120 灰度图。在 12 条扫描行上通过相对灰度阈值检测窄暗线段，枚举左右边界配对，用赛道宽度一致性评分选出一对，得到车辆坐标系中的 `(s, y, quality)`。`s` 向前、`y` 向左，长度单位为米。

模拟投影采用明确的行查找模型：

```
s(row) = 0.18 + 1.15 * ((119-row)/119)^1.5
half_span(row) = 0.12 + 0.65*s(row)
y(pixel,row) = (pixel-93.5)/93.5 * half_span(row)
```

它是可重复的透视近似，**不是 MT9V034 标定结果**。真实摄像头必须测量内参、安装位姿、畸变和每行的地面映射。当前阈值、线宽范围、0.44m 赛道宽度也是模拟参数。

## 2. 稳健路径拟合

用二次多项式表示局部中线：`y(s)=c0+c1*s+c2*s²`。构造 `phi=[1,s,s²]`，解加权最小二乘：

```
A = sum(w_i * phi_i * phi_i^T)
b = sum(w_i * phi_i * y_i)
c = inverse(A) * b
```

三次拟合中，后两次依据 0.018m Huber 阈值降低离群点权重。无法求逆、点少于 4 个或纵向跨度不足 0.15m 时进入丢线分支。

拟合误差产生协方差代理：

```
Sigma_c = max(0.004², weighted_SSE / max(sum(w)-3,1)) * inverse(A)
```

这只是启发式代理：IRLS 后的权重、结构化误配和测量相关性不符合严格独立高斯假设，所以不能称它为准确概率、95%区间或经过标定的不确定性。

## 3. 从路径误差传播到转向曲率

对 0.35～1.05m 范围内 9 个前瞻候选 L：

```
y_L = c0+c1*L+c2*L²
kappa_L = 2*y_L/(L²+y_L²)
Var(y_L) = [1,L,L²] * Sigma_c * [1,L,L²]^T
d(kappa)/d(y) = 2*(L²-y_L²)/(L²+y_L²)²
sigma_kappa = abs(d(kappa)/d(y)) * sqrt(Var(y_L))
```

选择代价最低的前瞻：

```
L_nominal = clip(0.25+0.22*v, 0.40, 0.75)
J(L) = (L-L_nominal)² + 0.12*sigma_kappa² + 3*max(0,L-s_max)²
```

代价权重含量纲，是本项目选定的工程调参值；这不是无量纲普适目标函数。短前瞻可能放大横向测量误差，过长前瞻可能超出已观测区域，候选选择显式权衡这两类问题。它是固定成本的离散搜索，不是 MPC，也不是 Unscented Transform。

舵机目标角：`delta=clip(atan(0.26*kappa),-0.48,+0.48)`。

## 4. 速度建议

所有曲率调速方法共用：

```
k_curve = abs(2*c2)/(1+c1²)^1.5
v_curve = sqrt(1.8 / max(0.25,abs(kappa),k_curve))
v_reference = min(1.8,v_curve)
```

完整方法进一步考虑观测范围与刹车距离：

```
d_available = max(0,s_max-0.20)
v_visibility = -a*tau + sqrt((a*tau)²+2*a*d_available)
a=2m/s², tau=0.12s
q = clip((n/12)*mean(quality)*exp(-rms/0.035),0,1)
v_command = min(v_reference,v_visibility)*(0.45+0.55*q)
```

这里 `s_max` 是检测到的最远边界对，不是经过验证的连续可行驶空间。没有障碍物检测、路面摩擦估计或道路边界的全预测约束，所以**这条刹车距离规则不能提供安全证明**。它是实验中的速度限制启发式。

## 5. 丢线分支

没有历史可靠拟合时立即给出零速建议。有历史拟合时保留上一曲率至多 0.18s；完整方法、消融和匹配基线逐步降低短暂丢线时的速度建议。固定与曲率调速基线保留 1.4m/s 建议至同一超时。所有方法在超过丢线期限后给出零速建议。重新获得有效测量后恢复。

真实车并不会在给出零速的瞬间停止；仿真中制动受 2m/s² 减速度限制。恢复逻辑没有空间地图，车辆可能停在无法重新检测的位置，所以 `stalled` 必须算作未完赛。

## 实际贡献与已有方法

## 实验后的判断

Lite 对应 `TL_NO_RISK` / Python 方法名 `no_risk`，只去掉代价中的 `0.12*sigma_kappa²`。它仍保留观测范围外推惩罚、可见范围限速和全部稳健拟合。两阶段完整方法均完赛72/120，Lite分别75/120和71/120；当前证据不足以证明敏感度项的稳定独立价值。完整方法保留为研究分支，Lite提供复杂度较低的选择；不能根据第一阶段单独宣称Lite更好。
