# 从学 C 到能讲清楚这个项目

## 阅读顺序

1. 看 `trustline.h`：结构体、数组、指针和数据单位。用 12 个全为零的中线点理解为什么舵机输出应为零。
2. 看 `tl_extract`：图像是一段连续字节，扫描行就是数组；暗线段的起止点、左右边界配对和宽度评分都能手算。
3. 看 `fit`：先理解 `y=c0+c1*s+c2*s²`，然后学习最小二乘和 3×3 矩阵求逆。修改一处扫描点，观察拟合变化。
4. 看前瞻候选循环：手算纯追踪曲率与导数，解释短前瞻为什么放大误差、外推为什么有风险。
5. 运行 `--quick`，比较相同场景和种子。阅读 `runs.csv`，区分完赛率、出界、停车、耗时和误差。
6. 独立完成一个改进：例如真实图像标定、单边界降级或结构化误配检测，并补上相应实验。留下你自己的修改记录。

## 可进一步研究的问题

- 为什么采用闭环实验，而不是只画出平滑中线？
- 控制器是否拿到了真实赛道？什么地方可以用真值？
- 协方差代理为什么不是准确概率？一致的错误边界会发生什么？
- 为什么必须比较采用相同限速策略的固定前瞻基线？
- 丢线停车算不算完成任务？减速是否总能避免出界？
- 你的具体实现贡献是什么？哪些方法来自已有研究？
- 模拟相机投影、运动学模型和真实竞速车有什么差别？
